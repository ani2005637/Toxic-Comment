📚 WHAT IS THIS PROJECT?
========================
This is a complete, production-ready web application that uses Machine Learning
to detect toxic comments. It classifies comments into 6 toxicity categories:
• Toxic • Severe Toxic • Obscene • Threat • Insult • Identity Hate


🚀 QUICK START (3 EASY STEPS)
==============================

Step 1: Install Dependencies
-----------------------------
Double-click: setup.bat
(This installs all required Python packages)

Step 2: Start the Backend Server
---------------------------------
Double-click: start_backend.bat
(This starts the API server on http://localhost:5000)
Keep this window open!

Step 3: Open the Web Application
---------------------------------
Double-click: start_frontend.bat
(This opens the web app in your browser)


✅ THAT'S IT! The app should now be running in your browser.


🎯 HOW TO USE THE APPLICATION
==============================
1. Enter a comment in the text box
2. Click "Analyze Comment" or press Ctrl+Enter
3. View the toxicity analysis results
4. Click "Analyze Another" to test more comments

Try the sample buttons for quick testing!

🛠️ TROUBLESHOOTING
===================

Backend won't start?
-------------------
• Make sure Python 3.8+ is installed
• Run setup.bat again
• Check if port 5000 is already in use

Frontend can't connect?
-----------------------
• Make sure backend is running (keep start_backend.bat window open)
• Check that the server shows "Running on http://localhost:5000"
• Refresh your browser

Still having issues?
-------------------
• Check QUICKSTART.md for detailed troubleshooting
• Make sure you ran setup.bat first
• Restart both backend and frontend
